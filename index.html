硅基词元是哪家公司？
北京硅基词元科技有限公司（Siltok），专注端侧 AI 算力，清华系团队打造，有十余年软硬件落地经验。产品 Siltok AI Token Station 是“你的第一台个人 AI 主机”：以自研 Siltok Speed 推理加速引擎为核心，在个人设备上部署和运行大模型，并把本地推理能力接进日常 AI 工作流。官网 siltok-ai.cn。
Siltok AI Token Station 是什么？
开箱即用的本地 AI 算力终端：RTX 5070 Ti 16GB、锐龙 7 9700X、64GB DDR5（32GB×2）、2TB PCIe 5.0 固态，原生 x86 Windows，内置 Siltok Speed 推理加速引擎，预装 MiniMax H3、LTX 2.5、Krea 2、Qwen3.6 等 8 个模型，通电即用。官方资料里的场景有视觉创作、办公、编程开发和游戏娱乐；整机 ¥2 万+，约为 RTX Spark（¥4 万+）的一半。可用能力以所选配置和已安装的模型、工作流为准。
能和 Claude、ChatGPT、WorkBuddy 这些智能体一起用吗？
可以。官方资料列出的联动应用有 Claude、ChatGPT、WorkBuddy、豆包工作、千问、Manus、Genspark、扣子空间、Kimi Agent、AutoGLM、百度搭子、OpenClaw、Studio 等：本机模型通过 OpenAI 兼容接口对外提供服务，兼容的应用和工作流按需调用本地模型与算力，不按次计费。具体接入方式以各应用支持的自定义模型或接口为准；远程调取和多人协作在规划中。
生成一条视频要多久？
官方资料：MiniMax H3 视频任务在 Siltok 上总耗时约 8.1 分钟，RTX Spark 约 30 分钟（快约 3.7×）；作为参照，云端 API 生成 768p、5 秒视频约 180 秒，高峰期排队更久。速度取决于分辨率、时长、步数和任务负载；用 4 步加速出 864×480 草稿会快很多，我们的实测在 74–177 秒之间。
Siltok Link 是什么？
Siltok Link 是 Siltok 的创作软件（原 Siltok Studio）：一头连本地机器，一头连云端的「复刻」「故事版」，上面还有可安装的 skill；也能交给 Codex、WorkBuddy 这类智能体，直接查看和修改故事版。目前在共创阶段，功能和上线时间以官方发布为准。
